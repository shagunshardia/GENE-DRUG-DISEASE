# NETWORK-BASED AND MACHINE LEARNING APPROACHES FOR PREDICTING GENE–DRUG–DISEASE RELATIONSHIPS
A Review and Data-Driven Exploration of Link Prediction for Drug Repurposing

Overview

This project explores how network-based approaches and machine learning can be used to identify relationships between genes, drugs, and diseases, with a particular focus on drug repurposing.

The project investigates how biological networks can integrate gene–disease associations and drug–gene interactions to identify potential therapeutic connections. It aims to understand how computational methods can help predict new drug candidates for existing diseases.

The initial data exploration focuses on Type 2 Diabetes Mellitus (T2DM), examining associated genes and their interactions with existing drugs.

Objectives

Explore gene–drug–disease relationships using publicly available biological databases.

Understand how biological networks represent interactions between genes, drugs, and diseases.

Investigate machine learning approaches for biological link prediction.

Explore potential drug repurposing opportunities for Type 2 Diabetes.

Review the applications of graph-based learning in computational drug discovery.

Methodology

The project follows a network-based computational approach:

Disease Identification: Select Type 2 Diabetes Mellitus as the target disease.

Gene Association Retrieval: Obtain disease-associated genes using Open Targets.

Drug–Gene Interaction Retrieval: Collect drug–gene interaction data using DGIdb.

Data Integration: Combine the datasets to explore connections between diseases, genes, and drugs.

Network Construction: Represent biological relationships as a heterogeneous network.

Link Prediction: Explore machine learning and graph-based methods to predict potential missing relationships.
