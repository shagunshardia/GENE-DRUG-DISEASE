# Build-a-Media-Catalogue
Media Catalogue is a Python-based application that organizes and manages different types of media, such as movies and TV series. It uses object-oriented programming concepts like inheritance, custom exceptions, and methods to add, validate, categorize, and display media items efficiently.
Features
Add movies and TV series to the catalogue
Validate media information
Separate movies from TV series
Display catalogue contents in an organized format
Handle invalid media using custom MediaError exceptions
Demonstrates inheritance, encapsulation, and polymorphism
Technologies Used
Python
Object-Oriented Programming (OOP)
Concepts Demonstrated
Classes and objects
Inheritance
Method overriding
Custom exceptions
List comprehensions
isinstance() and type()
String formatting and __str__() methods
Purpose
The project was created to practice Python OOP concepts while building a simple and functional system for managing different types of media.
